# Security policy

Neutrin0 has no production network. Treat every release as experimental.

## Reporting a vulnerability

Report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/Rorical/Neutrin0/security/advisories/new).
Do not open a public issue for a vulnerability.

Include the affected component, the commit you tested, and the steps or input
that reproduce the problem. Consensus safety, proof soundness, slashing
accountability and validator key handling issues are the most valuable reports.
